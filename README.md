# NodeWatch — распределённый мониторинг узлов

Курсовой проект: «Распределённая система мониторинга и аналитики состояния
вычислительных узлов с целью выявления несанкционированной активности».

* на каждом компьютере работает **агент** — он каждые 2 секунды измеряет
  процессор, диск, сеть, запуск процессов и потоков, память и шлёт это на сервер;
* **сервер** складывает данные, сравнивает их с «нормой» каждого компьютера и,
  если видит подозрительное, создаёт **инцидент** со снимком процессов;
* всё видно в **веб-панели** — с этого же компьютера, со второго ноутбука или с телефона.

| Что | Протокол | Порт |
|---|---|---|
| Метрики от агентов | UDP (подпись HMAC-SHA256 + сжатие zlib) | 9999 |
| Команды агентам и CLI | TCP (JSON-строки, вход по общему секрету) | 9998 |
| Веб-панель | HTTP | 8080 |

---

## 1. Что нужно

* Windows 10/11 или Linux;
* Python 3.8 или новее;
* одна библиотека — `psutil`. Батники ставят её сами при первом запуске
  (нужен интернет один раз). Вручную: `pip install -r requirements.txt`.

---

## 2. Запуск на одном компьютере

1. Двойной щелчок по **`start-server.bat`**. В окне появятся строки вида

   ```
   Веб-панель:
     http://192.168.1.10:8080/#token=3f9c…
     http://127.0.0.1:8080/#token=3f9c…
   ```
2. Двойной щелчок по **`start-agent.bat`** — агент подключится к `127.0.0.1`.
3. Скопируйте ссылку `http://127.0.0.1:8080/#token=…` в браузер. Через 2–3 секунды
   компьютер появится на вкладке «Агенты» со статусом «онлайн».

Окна сервера и агента не закрывайте — это и есть работающая программа.
Остановить: `Ctrl+C` в окне.

Из VS Code: откройте папку проекта, `Terminal → New Terminal`, и выполните
`.\start-server.bat`, во втором терминале — `.\start-agent.bat`.


## 3. Два ноутбука (или больше)

Оба ноутбука должны быть в одной сети (один Wi-Fi или раздача с телефона).

**Ноутбук-сервер:**
1. Узнайте его IP: он печатается в окне сервера (строка `http://192.168.x.x:8080/…`),
   или выполните `ipconfig` и посмотрите «IPv4-адрес».
2. Откройте порты (один раз): правый щелчок по `scripts\open-firewall.bat` →
   «Запуск от имени администратора». Если при первом запуске Windows спросит
   «Разрешить доступ Python?» — отметьте **частные сети** и нажмите «Разрешить».
3. Запустите `start-server.bat`.
4. При желании запустите и на нём агента: `start-agent.bat`.

**Второй ноутбук (агент):**
1. Скопируйте на него папку проекта.
2. Откройте командную строку в папке и выполните
   ```
   start-agent.bat 192.168.1.10
   ```
   где `192.168.1.10` — IP сервера. Можно сразу задать имя узла:
   `start-agent.bat 192.168.1.10 noutbuk-2`.
   (Или открыть `start-agent.bat` блокнотом и поменять строку `set SERVER=...`.)

**Секрет должен быть одинаковым везде.** Он задан в батниках строкой
`set MON_SECRET=kursovoy-proekt-2026-secret`. Если меняете — меняйте во всех
батниках (или задайте переменную окружения `MON_SECRET`, или поле `"secret"` в `config.json`).
Секрет по сети не передаётся: стороны доказывают, что знают его, через случайное
число и HMAC (challenge-response). Агент с чужим секретом получит `auth failed`,
а его UDP-пакеты сервер отбросит.

Если агент пишет «нет связи с сервером» — проверьте IP, что сервер запущен и что
открыты порты (пункт 2). Агент сам переподключается каждые несколько секунд.

## 4. Панель с телефона

1. Телефон подключите к той же сети Wi-Fi, что и сервер.
2. Откройте в браузере телефона ссылку из окна сервера, но с IP сервера:
   `http://192.168.1.10:8080/#token=…` (токен — длинная строка после `token=`).
3. Токен запоминается в браузере, дальше достаточно `http://192.168.1.10:8080/`.

Токен вычисляется из секрета, поэтому после перезапуска сервера ссылка не меняется.

## 5. Командный интерфейс (CLI)

`cli.bat` (Windows) или `python cli.py` — подключается к серверу по TCP 9998.
Без аргументов открывается интерактивный режим.

```
cli.bat agents                              список узлов и их статус
cli.bat report                              сводка по всем узлам
cli.bat report lab-pc-1                     сводка mean/p95/max/last по узлу
cli.bat incidents --status open             инциденты (фильтры --node --rule --status)
cli.bat incident INC-0003                   карточка инцидента
cli.bat ack INC-0003                        подтвердить
cli.bat agent lab-pc-1 pause                пауза (resume — продолжить)
cli.bat agent lab-pc-1 interval 1           интервал отправки, с
cli.bat agent lab-pc-1 snapshot             снимок процессов
cli.bat agent @lab groups lab,office        команда всей группе (@группа) или всем (*)
cli.bat thresholds mem_jump_pct=3 burst_z=4 изменить пороги на лету
cli.bat thresholds --reset                  вернуть пороги по умолчанию
cli.bat test_incident lab-pc-1 MEM_JUMP     тестовый инцидент
cli.bat forget lab-pc-1                     убрать узел из списка
cli.bat --server 192.168.1.10 agents        к серверу на другом компьютере
```
